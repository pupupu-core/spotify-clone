# Sprint 3: Directives, Pipes & Forms

## Что было сделано

- Настроила локальное окружение для backend-разработки:
  - установила Docker;
  - запустила PostgreSQL через Docker Compose;
  - применила Prisma-миграции;
  - настроила переменные окружения.

- Разобралась со структурой backend-проекта на NestJS и принципом работы слоёв приложения:

  `Jamendo API --> JamendoClient --> Step --> Workflow --> Controller --> Module`

- Добавила поддержку новых endpoint-ов Jamendo:
  - `artists/tracks`
  - `artists/albums`
  - `artists/musicinfo`
  - `albums/tracks`

- Реализовала методы в `JamendoClient` для работы с новыми endpoint-ами.

- Создала DTO-схемы на Zod, интерфейсы, типы и мапперы для обработки ответов Jamendo API.

- Добавила общие модели и интерфейсы, используемые как на backend, так и на frontend.

- Начала реализацию backend API через создание:
  - `Steps`;
  - `Workflows`;
  - `Controllers`;

  для новых сущностей.

---

## Проблемы

- Ранее не работала с backend-частью проекта и не понимала архитектуру приложения.

- Возникли сложности с первым запуском backend-проекта и настройкой Docker.

- Backend не запускался из-за отсутствия сгенерированного Prisma Client.

- Было непонятно, как связаны между собой:
  - `Module`;
  - `Controller`;
  - `Workflow`;
  - `Step`.

- Пришлось разбираться в документации Jamendo API и самостоятельно проектировать типы для ответов.

- Некоторые новые endpoint-ы не отображались в Swagger, из-за чего потребовалось изучить процесс регистрации модулей и контроллеров в NestJS.

---

## Решения

- Изучила существующую реализацию функционала **Track Discovery** и использовала её как шаблон для создания новых endpoint-ов.

- Настроила Docker, подняла локальную базу данных PostgreSQL и выполнила Prisma-миграции.

- Сгенерировала Prisma Client и разобралась с зависимостями backend-проекта.

- Использовала Swagger для проверки маршрутов и поиска ошибок в конфигурации.

- Создала отдельные DTO, типы и мапперы для каждого нового endpoint-а, чтобы обеспечить строгую типизацию.

- На основе реальных ответов Jamendo API описала внутренние модели приложения.

---
