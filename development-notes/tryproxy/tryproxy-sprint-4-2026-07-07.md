# Sprint 4: HTTP, RxJS & Testing (@angular/common/http, rxjs, @angular/core/testing)

## What was done & Problems:

### Backend

1. Добавил локальное S3-compatible хранилище MinIO и в docker-compose добавил сервис, bucket init, который инитит бакет при поднятии докера и `S3StorageService` для работы с клиентом S3.

Основная проблема, НИЧЕГО НЕ ПОНЯТНО В ДОКЕ AWS, где что смотреть, что читать, очень трудно, ничего не понятно, трудно, без разжевывания с ИИ дока показалась нечитаемой.

2. Добавил загрузку своего трека. Стандарт по ендпоинтам: создать, удалить трек, а также получение треков для всех загруженных пользователями `tracks/community` и получение 'своих' треков, загруженных только пользователем `account/tracks`.

Проблема возникла с перемоткой трека, оказалось недостаточно просто вернуть трек из хранилища как stream для прослушивания, надо добавить поддержку заголовка HTTP `Range`, чтобы браузер мог подгружать и перематывать аудио. Также была микро проблема с audioUrl для треков, но об этом во фронтенд части.

3. Добавил поддержку пустого `username` и подстановку `email` при регистрации в БД для профиля юзера. Оказывается, я вовсе упустил тот факт, что при создании нового аккаунта в таблицу `Account`, табличка профиля с данными о юзере никак не обновлялась, решил просто `upsert`-ом в новом step [UpsertAccountProfileStep]() для нашего workflow при регистрации. Теперь создается/обновляется таблица `Profile`, а `username` опциональный и при пустом значении дефолтится в `email`.

4. Пофиксил пару продовых проблем с CORS для основного домена, добавил `SkipThrottle` для `refresh`/`me`, потому что показалось, что ставить троттл на refresh было излишне, также обратил внимание, что ендпоинт `/me` отвечал с кодом 304, а не 200, оказалось, что нужно добавить заголовок для работы кэша в браузере с `no-store`.

### Frontend

1. Добавил ассеты: фавиконку, Open Graph мета-теги для красивой карточки на ссылку и картинку. Также посмотрел, что такое robots.txt и sitemap.xml, надеюсь SEO для сайтов в эпоху ИИ еще имеет значение, и это как-то повлияет на выдачу поисковиком.

2. Пофиксил проблему с путаницей доменов для локальной работы и прода. Добавил отдельные настройки окружений в Angular: environment для локальной разработки и environment.prod для продакшн-сборки. Через них теперь задается apiOrigin, а endpoint-ы собираются уже с учетом того, куда фронт должен ходить за API. Узнал о file replacements в ангуляре: при обычной разработке ангуляр берет dev environment, а при production build автоматически подставляет prod environment.

```json
// project.json nx-вский 'angular.json'
"build": {
      "configurations": {
        "production": {
          "fileReplacements": [
            {
              "replace": "apps/web/src/environments/environment.ts",
              "with": "apps/web/src/environments/environment.prod.ts"
            }
          ]
        }
      }
```

3. Доработал Home/Discover страницу наконец-то для отображения популярных треков и последних релизов. Столкнулся с неожиданной сложностью имплементации макета, дело в том, что элементы жанров, чипы, заполняют пустое пространство всего контейнера, а кол-во жанров может быть динамическим. Достаточно нетривиальная задача, похожая на masonry-grid, где все элементы могут менять размер своего контейнера.

4. Сделал красивые формы регистрации и авторизации, нашему фронтенд-лиду понравились, вот так вот! Посмотрел, что такое material/angular. Понравилось, как там реализованы лейблы для инпутов и отображение ошибок валидации.

Ввиду того, что наша публичная страница это страница авторизации, то была проблема, как показать юзеру наше приложение, не вынуждая его регаться? Решили добавить просто кнопку логина с захардкоженными данными, так появился хинт кнопкой `Just exploring?` `Try demo account`

5. Личная гордость - добавил миксин `shake` с простейшей CSS анимацией на ошибку в респонсе для кнопки сабмита. Прочитал в твиттере тейк, что такой подход улучшает UX, форма немножко оживает и не выглядит скучной, юзер интуитивно понимает, что какое-то действие не может завершиться с успехом.
